# 🗂️ File Organizer

A simple and efficient CLI tool to **automatically** or **manually** organize your files into categories like Images, Documents, Videos, Music, and Archives.

---

## 📦 Features
- 📂 Automatically organize your Downloads folder in real-time.
- 🛠️ Manually organize any folder.
- 🔥 Clean, modular project structure.
- 🐍 Built with Python and Watchdog.

---


## 🛠️ Tech Stack
- Python 3.x

- Watchdog (for file monitoring)

- pathlib, shutil, os
